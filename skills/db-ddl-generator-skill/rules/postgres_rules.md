# PostgreSQL Rules

- Quote identifiers with double quotes only when required; otherwise prefer unquoted lowercase identifiers.
- Use `CREATE TABLE schema.table` when schema is known; default schema is `public`.
- Use `GENERATED BY DEFAULT AS IDENTITY` only when source explicitly says auto-increment/identity.
- Use `PRIMARY KEY (...)` as a table constraint.
- Emit secondary indexes after table creation with `CREATE INDEX idx_name ON schema.table (col);`.
- Emit comments as separate statements:
  `COMMENT ON TABLE schema.table IS '...';`
  `COMMENT ON COLUMN schema.table.column IS '...';`
- Prefer `text` for unbounded strings.
- Use `numeric(p, s)` for decimal types.
- Use `jsonb` for JSON unless the user requests `json`.
- Use `timestamp` for timestamp without timezone and `timestamptz` only when source semantics include timezone.
